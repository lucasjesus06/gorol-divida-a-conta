# Instruções para o agente

Este é o **frontend** do GoRolê. As regras de trabalho, as decisões do projeto e as pendências ficam no repositório do backend, `lucasjesus06/gorole-service`:

- `CLAUDE.md`: regras de trabalho do agente (valem também para este repositório).
- `docs/decisoes.md`: stack, glossário, regras de negócio, arquitetura e forma de trabalho.
- `docs/pendencias.md` e `docs/evolucoes.md`: o que falta e o que fica para depois.
- `docs/produto/especificacao-funcional.md`: especificação original do produto.

Leia esses documentos antes de qualquer tarefa. Se o `gorole-service` não estiver disponível na sessão, peça ao Lucas para incluí-lo.

- [`README.md`](README.md): como rodar, organização do código e padrão de branches.
